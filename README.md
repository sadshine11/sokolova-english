# Сайт репетитора по английскому языку

Одностраничный сайт с формой записи. Статическая сборка на Astro + TypeScript,
без фреймворков в браузере.

**Демо:** https://sadshine11.github.io/sokolova-english/

## Как поменять тексты

Весь текст сайта лежит в одном файле — [`src/content/site.ts`](src/content/site.ts).
Вёрстку трогать не нужно: правите строки в этом файле, и всё обновляется.
Там же цены, отзывы, вопросы-ответы, контакты и адреса разделов.

## Как поменять фотографии

Сейчас на местах фотографий стоят рисованные заглушки в стиле сайта.
Чтобы поставить настоящие снимки:

1. Положите файлы в `public/img/` — например `portrait.jpg`, `photo-1.jpg`.
2. В `src/content/site.ts` замените расширение `.svg` на ваше в полях `src`.
3. Там же поправьте `alt` — короткое описание того, что на снимке
   (его читают вслух программы для незрячих и показывают, если картинка не загрузилась).

Рекомендуемые размеры: портрет — 1000×1250, горизонтальные — 1600×900,
остальные — 1500×1000. Формат `.jpg` или `.webp`.

## Куда приходит заявка

По умолчанию форма работает в демонстрационном режиме: она проверяет поля
и показывает сообщение, но никуда не отправляет.

Чтобы заявки приходили на почту, заведите бесплатную форму на
[Formspree](https://formspree.io) или [Web3Forms](https://web3forms.com)
и создайте в корне проекта файл `.env`:

```
PUBLIC_FORM_ENDPOINT=https://formspree.io/f/ваш-код
```

После пересборки заявки пойдут на указанный адрес. Сообщение об ошибке
и запасной вариант — написать в Telegram — уже встроены.

## Команды

```bash
npm install          # поставить зависимости
npm run dev          # локальный сервер для разработки
npm run build        # production-сборка в dist/
npm run preview      # посмотреть собранный сайт
```

Вспомогательные:

```bash
node scripts/images.mjs   # пересобрать иллюстрации-заглушки
node scripts/og.mjs       # пересобрать картинку для превью в мессенджерах
node scripts/shots.mjs    # снимки страниц на четырёх ширинах экрана
node scripts/check.mjs    # проверка интерактива и доступности
```

## Публикация

При пуше в `main` сайт пересобирается и выкладывается на GitHub Pages
(см. `.github/workflows/deploy.yml`).

Если сайт переедет на свой домен, поправьте `site` и `base` в `astro.config.mjs`:
для собственного домена `base` нужно убрать.

## Как устроено

- `src/content/site.ts` — весь текст и данные.
- `src/components/` — разделы страницы, у каждого свои стили рядом с разметкой.
- `src/styles/tokens.css` — цвета, шрифты, размеры, отступы. Меняете здесь — меняется везде.
- `src/scripts/` — поведение: появление блоков, меню, табы ОГЭ/ЕГЭ, галерея, форма.
- `public/` — картинки и шрифты, которые отдаются как есть.

Шрифты (Unbounded, Golos Text, Caveat) лежат внутри проекта и не тянутся
со сторонних серверов — сайт не зависит от доступности Google Fonts.
